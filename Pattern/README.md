# 🌟 Pattern Printing Algorithms in Java

This directory contains **283 Java pattern printing programs** organized into three difficulty levels, taking you from beginner rectangular grids all the way to intricate hollow alphanumeric shapes, Pascal's triangles, and symmetric butterflies.

---

## 📂 Sub-folder Breakdown

### 1. [`Pattern/Level 1`](file:///c:/Users/ANAS%20SIDDIQUI/Desktop/DSA%20Q/Pattern/Level%201) (11 Programs: Q01 to Q11)
- **Grid Foundations**: Basic rectangular and square grids of stars, rows of numbers, columns of numbers, alternating 0/1 grids, character grids.
- **Focus**: Nested loop basics, row loop index $i$, column loop index $j$.

### 2. [`Pattern/Level 2`](file:///c:/Users/ANAS%20SIDDIQUI/Desktop/DSA%20Q/Pattern/Level%202) (227 Programs: Q12 to Q238)
- **Triangles & Inverted Triangles**:
  - Right-angled triangles (Left & Right aligned)
  - Inverted right-angled triangles
  - Mirrored triangles
- **Numeric & Alphabet Variations**:
  - Consecutive numbers, reverse numbers, palindromic number rows
  - Alphabet stairs (A, AB, ABC...), repeating letters, reverse alphabets
  - Alternating binary triangles (Floyd's triangle variations)
- **Pyramids & Hollow Pyramids**:
  - Centered full pyramids with spacing
  - Inverted centered pyramids
  - Hollow pyramids with boundary condition logic
  - Diamond halves and zig-zag borders

### 3. [`Pattern/Level 3`](file:///c:/Users/ANAS%20SIDDIQUI/Desktop/DSA%20Q/Pattern/Level%203) (45 Programs: Q239 to Q283)
- **Advanced Geometric & Symmetric Shapes**:
  - Full solid and hollow diamonds
  - Hourglass patterns
  - Butterfly and Bow-tie patterns
  - Pascal's Triangle (Combinatorial ${}^nC_r$ & additive methods)
  - Number spirals and concentric square frames
  - Interlocking star and numeric polygons

## 🚀 How to Run

```bash
# Run any pattern program directly with Java 11+
java "Pattern/Level 1/Q01.java"
java "Pattern/Level 2/Q25.java"
java "Pattern/Level 3/Q239.java"

# Or from compiled class files:
java -cp "class_files/Pattern/Level 3" Q239
```
